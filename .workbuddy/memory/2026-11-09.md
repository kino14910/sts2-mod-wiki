## CardRow 描述内联词条链接修复

- 症状：`CardDescription.svelte` 的 `desc-body` 里金色术语渲染为
  `<span class="wiki-card-link" role="note">易伤</span>`：无 href、无能力图标、无 wiki tooltip。
- 根因：`href={seg}` 把整个 segment 对象传给 `WikiEntity`（该组件不接受 href prop）；
  且旧 `powerEntries` 只按 `termIndex()` 的 power 词条合成 `kind:'power'` 的伪 WikiEntry，
  而 `WikiEntity` 只对 `kind==='card'` 生成 href，因此必然是 null；tooltip 只是 glossary 纯文本摘要。
- 修复：`WikiEntity` 增加可选 `href` / `tooltip` / `icon` prop（不传时保持原行为），
  `icon` 由 `WikiPowerIcon` 渲染，`HoverTooltip` 改用 `registerTip` 实测尺寸定位；
  `a.wiki-card-link:hover` 加下划线高亮。
- `CardDescription` 改用 locale 无关的术语解析：`WIKI_ENTRIES`（卡名/卡牌 tooltip）、
  `wikiTerm()`（WIKI_TERMS 富文本 tooltip + 英文名图标）、`termIndex()`（glossary href），
  另用 `POWERS`/`KEYWORDS` 英文名索引兜底 href；描述里的 HTML 实体先解码再查表。
  `variant==='face'`（卡面）保持非交互，避免卡面里出现链接/图标。
- 易伤现在渲染 `<a href="/power/VulnerablePower">` + `vulnerable_power.png` 图标 + Vulnerable 富文本 tooltip；
  `/keywords#exhaust` 等关键词链接同步生效。中英两种 locale 均验证。
- 验证：`pnpm check` 0/0；SSR HTML、Chrome 扩展点击跳转到 `/power/VulnerablePower`、
  同类词条「格挡」hover 出 Block tooltip 均已确认。注：本会话 `cua_move` 不触发页面 mouseenter，
  用 click 前置的 mousemove 才能验证 tooltip。

## WikiIcon 统一组件（取代 WikiPowerIcon / WikiRelicIcon）
- 需求：图标组件在「当前正处于对应详情页路由」时渲染 `<span>`（保留 `margin-left:0.1em;font-weight:700` 的标签样式），否则渲染 `<a>` 跳转到详情页；卡牌链接也要用该组件，且组件内按卡牌 type+rarity 选 `static/images/card_icons/{Color}_{Type}_{Rarity}.png`。
- 用户澄清：例「当前在 /power/Vulnerable 就把 Vulnerable 显示成 span」→ 即 非详情页→a、详情页→span（标准 self-link 抑制）。
- 组件形态：合并为统一 `WikiIcon.svelte`（`kind: 'power'|'relic'|'card'`，props: name/src/card/label/href/asLink）。删掉旧 `WikiPowerIcon.svelte` / `WikiRelicIcon.svelte`。
- 路由判定：`page.url.pathname`（`$app/state`）比对 href，抽到 `#lib/data/wiki-links.ts` 的 `isSelfLink()`（纯函数，组件与 WikiEntity 共用，避免重复）。
- `wiki-links.ts`：按 name 建 POWERS/RELICS/CARDS 索引；`powerHrefByName`/`relicHrefByName`/`cardHrefByName`/`cardByName`/`powerIconByName`/`cardIcon`；`cardIcon` 用确定性 Set 生成可用图标名（Colorless 无 Common），type 为 status/curse/quest 时回退 null。
- `asLink=false`：组件只渲染 `<span>` 图标（不自带链接），供 WikiEntity 等已有 `<a>` 包裹处复用，避免嵌套 `<a>`；`aria-current` 由外层负责。
- 接线：`WikiText` 行内 power→`kind="power"`、relic→`kind="relic"`（token 现带 name+icon 两字段）；`WikiEntity` 卡牌条目渲染卡牌图标（按 type+rarity），并在 `isSelfLink` 命中时把外层 `<a>` 降级为 `<span aria-current>`。
- 验证：`pnpm check` 0/0（svelte-check）。`pnpm build` 仍被本沙箱 safe-delete 守卫拦截（删 `.svelte-kit/output` 超阈值），属环境限制非代码问题。
