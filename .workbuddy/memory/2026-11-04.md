## 卡牌字体：套用原版 Kreon 排版

- 来源：`scenes/cards/card.tscn` + `src/Core/Nodes/Cards/NCard.cs` + `src/Core/Helpers/StsColors.cs`。
  - 标题 `TitleLabel`：FontVariation(kreon_regular) + `spacing_glyph=1`，font_size 26，`outline_size 12`，fill `#FFF6E2`，shadow (2,2)/18.8% 黑；描边色由 `GetTitleLabelOutlineColor()` 按稀有度取：basic/common/token/ancient `#4D4B40`、uncommon `#005C75`、rare `#6B4B00`、curse `#550B9E`、quest `#7E3E15`、status `#4F522F`、event `#1B6131`。
  - 类型铭牌 `TypeLabel`：kreon_bold，font_size 16，`Color(0,0,0,0.753)`，无描边。
  - 费用 `EnergyLabel`：kreon_bold，font_size 32，`outline_size 16`，fill = cream，描边 = `CardPoolModel.EnergyOutlineColor`（ironclad `#802020`、silent `#1A6625`、regent `#803D0E`、necrobinder `#803367`、defect `#1D5673`、colorless `#5C5440`）。
  - `kreon_bold_glyph_space_one` 实际用于 `StarLabel`（星球费用），不是能量费用。
- 关键坑：Godot `outline_size` 不能直接当 CSS 描边宽度。按 `outline_size/2` 折算（标题 4cqw）会把字母糊成一坨黑块。改用按字级等比 `-webkit-text-stroke: 0.16em` + `paint-order: stroke fill`，外侧约 2px，视觉与原版一致。
- `paint-order` 对 HTML 文本支持：Chrome/Edge 123+、Safari 11+、Firefox 60+，可用作「先描边后填充」，正好对应 Godot 渲染顺序。

## 中文字体：按原版 ZhsFontPathSet 接入

- 来源：`src/Core/Localization/Fonts/FontPathSets/ZhsFontPathSet.cs` + `FontManager.GetSubstituteFont` + `FontControlUtils.ApplyLocaleFontSubstitution`。
  - Regular → `fonts/zhs/NotoSansMonoCJKsc-Regular.otf`（界面/正文/卡牌标签）
  - Bold → `SourceHanSerifSC-Bold.otf`；Italic → `SourceHanSerifSC-Medium.otf`（仅富文本加粗/强调）
  - Kreon / Inter 均无中文字形，中文全部走替换；`FontType.Regular` 用在绝大多数 Label 上，所以原版中文以黑体为主、加粗用宋体。
- 站点映射：`--font-display` 中文 → Source Han Serif SC（Medium 400 / Bold 700）；`--font-sans` 中文 → Noto Sans Mono CJK SC。Latin 仍走 Kreon / Inter（栈里排在中文前）。
- 体积：直接用 fontsource 的 CJK 包会让产物 +27MB（811 个 woff/woff2）。改为从游戏自带 OTF 按站点实际用到的 932 个汉字裁剪：
  `python scripts/subset-zh-fonts.py` → `static/fonts/zh/*.woff2`，合计约 1.09MB。`--all-common` 可并入 GB2312 一级字（约 1.7MB/字重，慎用）。
- 坑：`@font-face` 不写 `unicode-range` 时，英文页面只要有 Inter 缺字的标点就会把整套中文字体拉下来（+297KB）。三份字体都补 `unicode-range: U+3000-303F, U+4E00-9FFF, U+FF00-FFEF;` 后，英文页零中文字体请求。
- 语言切换按钮的「中文」二字改用系统 CJK 字体（`SiteHeader.svelte` 的 `.locale-zh`），避免英文页为两个字付字体开销。
- 遗留：`static/fonts/` 下有 67MB 未引用的 MiSans（10 个 woff2 + 20MB VF ttf），已无任何 CSS 引用，可清理。
